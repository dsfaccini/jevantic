# Jevantic

Jevantic is a Python library being designed for typed, probabilistic decisions with Jev.

The goal is a maintainable public interface with Pydantic AI's flexibility and engineering discipline. Common operations should be convenient while lower-level composition remains available. Pydantic AI Harness is an intended downstream consumer.

Current stage: research and conceptual design. No runtime implementation exists yet.
