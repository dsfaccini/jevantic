# Jevantic design vocabulary

## Knowledge

- [TypeSafe primitives](https://docs.typesafe.ai/primitives): the behavior of Choice, Score, and Noul. Start here for what the model can return.
- [TypeSafe confidence](https://docs.typesafe.ai/confidence): distinguish answer probabilities from the provider's confidence statistic.
- [Python function definitions](https://docs.python.org/3.13/reference/compound_stmts.html#function-definitions): decorator syntax and its equivalent function transformation; a concrete example of syntactic sugar.
- [TypeSafe parallel questions cookbook](https://docs.typesafe.ai/cookbooks/parallel_questions): shared-state batching and application use of named answers.
- [Cookbook research](../research/cookbook-patterns.md): the project's source-linked comparison of recurring workflows, with unreplicated claims labeled.

## Gaps

The vocabulary pages explain this project's design choices. They do not establish model accuracy or suitable thresholds for an application; those require its own evaluation data.
