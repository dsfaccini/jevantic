KEEP BESIDE AN API PROPOSAL

The words we are using

Each term names a different responsibility in the library or its caller.

TermMeaning hereConcrete example
PrimitiveA basic model operation that other behavior composes.Noul, Choice, or Score.
StateThe content a model evaluates.A command and the user's intent.
Question / answerThe judgment requested / the values returned.A risk predicate / its estimated probability.
RubricOrdered descriptions defining the levels of a Score.Incomplete → usable → complete.
ErgonomicsHow clear, convenient, and hard to misuse an interface is.The editor knows the selected value is a Team.
Convenience APIA reusable interface that packages common work.An assessment function that builds several questions.
Syntactic sugarShorter syntax with an equivalent underlying meaning.Python's decorator notation.
AbstractionA boundary that exposes useful operations while hiding their implementation details.Jevaluator handles SDK execution and answer validation.
BatchSeveral independent questions sharing one state and one logical API call.Score one draft for relevance and clarity. SDK retries may make more HTTP attempts.
Fan-outRun independent evaluations over different inputs, with explicit concurrency.Evaluate a collection of documents.
Policy / workflowA rule for what action to take / the sequence of evaluations and actions.Review high-risk commands; rank candidates, then inspect a shortlist.
Backend / adapterThe engine performing an evaluation / a translator to its interface.Jev / code that sends Jev's request format.
Probability / confidenceAn outcome estimate / the provider's distribution summary.Keep both values; do not substitute one for the other.
Static typing / validationCheck caller code before execution / check actual values at runtime.Reject an incorrect answer attribute / reject an unrequested option.
Sources: TypeSafe primitives, confidence, Python function definitions. API examples describe Jevantic's developing alpha; they do not claim that model judgments are infallible.
